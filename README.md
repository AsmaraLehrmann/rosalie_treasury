# Scripts created for the treasury of Rosalie, HAUS Project

## Income Report
Reads a multi-tenant ledger export and produces an income treasury report for one house, both houses, or a combined total, over a chosen date range.

**Report covers:** rent billed, other charges billed, amount collected, collection rate, and an arrears list (who owes what) as of the end of the selected period.
Run the cells top to bottom. You'll be prompted for the ledger filename, how to handle any unrecognized property tags, the house (or both), and the date range and nothing needs to be edited in the code itself.
### Instructions for income_report.ipynb
Make a Multitenant Ledger report on Rentec. Select date range hauses or units. Export report as csv
